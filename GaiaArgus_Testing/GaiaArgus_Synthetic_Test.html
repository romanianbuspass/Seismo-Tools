Gaia-Argus Synthetic Testing

This is a quick step by step guide for testing each module with synthetic signals.
Once each stage passes we will move onto testing with sensors.

Phase 1: Data Intake and Core Visualization

1. Data Ingestion & Live Waveform

Synthetic Input: Generate a 100 Hz, 3-component miniSEED file containing a pure 1 Hz sine wave with a known amplitude and a deliberate DC offset.

Test Execution: Load the file via the offline miniSEED mode or the Omega Directory Watcher. Open the Live Waveform module.

Expected Outcome Pass/Fail Actual Outcome / Notes
The Canvas Waveform renderer must display the loaded trace immediately.
Applying the Box Select Mode and dragging across the sine wave should produce an Amplitude readout matching the synthetic input's known amplitude.
The chart should enforce the render cap of 4,000 points per visible channel.

2. QC Matrix

Synthetic Input: A synthetic SeedLink stream where specific packets are intentionally dropped to create sequence discontinuities.

Test Execution: Connect the stream and monitor the QC Matrix table. Toggle the Mute switch for the affected stream.

Expected Outcome Pass/Fail Actual Outcome / Notes
The dropped packets must register on the Gap counter, changing the display to a red badge showing the number of gap events.
Clicking the Mute toggle must change the status pill from Active to Muted (amber).

3. Helicorder

Synthetic Input: A 24-hour continuous synthetic background noise file punctuated by distinct, high-amplitude impulse spikes at known intervals.

Test Execution: Load the file and navigate to the Helicorder view.

Expected Outcome Pass/Fail Actual Outcome / Notes
The drum plot must show time advancing left to right within each row, wrapping to the next row below.
The display must lock every row to the same Y-axis scale based on the global peak amplitude.
The synthetic impulses must appear as sharp vertical deflections on the respective time rows.

Phase 2: Spatial and Wavefield Analysis

4. Network Map & Polarization Analysis

Synthetic Input: A 3-component trace simulating a perfect linear P-wave (identical, in-phase sine waves on Z, N, and E) yielding a theoretical 45° back-azimuth and high rectilinearity. Ensure the synthetic PGA exceeds 0.02 g.

Test Execution: Run the Polarization analysis with the rectilinearity threshold set to 0.7. Observe the Network Map.

Expected Outcome Pass/Fail Actual Outcome / Notes
The Polarization module must report a Rectilinearity (R) approaching 1.0 (perfect linear P-wave) and trigger the P-WAVE TRIGGER badge.
On the Network Map, the station marker must transition to an amber/red colour and pulse due to the > 0.02 g PGA.
The Network Map must automatically draw a polyline vector from the station marker in the computed back-azimuth direction.

5. Orbit 3D

Synthetic Input: Use the same linear P-wave synthetic file from the Polarization test.

Test Execution: Open the Orbit 3D module to visualize the 3-C displacement.

Expected Outcome Pass/Fail Actual Outcome / Notes
The 3D scatter plot must render an elongated, needle-like trajectory aligned with the direction of propagation.

Phase 3: Spectral and Structural Analysis

6. Response Spectra & Spectrogram

Synthetic Input: A synthetic sum of two pure sine waves (e.g., 2 Hz and 10 Hz) followed by a swept-sine (chirp) signal.

Test Execution: Capture a snapshot in the Response Spectra module. Compute the Spectrogram using NFFT=256.

Expected Outcome Pass/Fail Actual Outcome / Notes
The Response Spectra PSD plot must show sharp spectral peaks at exactly 2 Hz and 10 Hz.
The Spectrogram heatmap must plot Frequency on the Y-axis and Time on the X-axis, displaying the chirp as a diagonal line across the time-frequency matrix.

7. Kinematics

Synthetic Input: A single sinusoidal acceleration pulse with a built-in DC offset.

Test Execution: Observe the integrated velocity and displacement traces. Toggle the High-Pass (HP) filter.

Expected Outcome Pass/Fail Actual Outcome / Notes
Without the HP filter, the DC offset must integrate into a ramping velocity signal.
When the HP filter is enabled, the integration drift must be suppressed, returning the post-motion velocity baseline to flat.

8. OMA / FDD

Synthetic Input: Two channels of synthetic broadband noise, both filtered to contain a hidden, shared resonance peak at exactly 2.5 Hz.

Test Execution: Run the FDD analysis with the FFT block size (nperseg) set to 1024.

Expected Outcome Pass/Fail Actual Outcome / Notes
The SV1 curve (teal) on the FDD plot must show a distinct, isolated peak at 2.5 Hz.
The Modal Properties Table must automatically detect and list this natural frequency alongside its half-power damping ratio.

9. HVSR

Synthetic Input: 3-component noise where the Z component has a spectral notch at 3 Hz, and the N/E components have corresponding peaks at 3 Hz.

Test Execution: Assign the Z, N, and E streams and compute the HVSR.

Expected Outcome Pass/Fail Actual Outcome / Notes
The H/V ratio spectrum (teal curve) must display a peak at the fundamental resonance frequency f_0 = 3 Hz.

10. Ambient Noise (Δv/v)

Synthetic Input: Generate two identical noise traces for the reference stack. For the subsequent "current" block, artificially shift one trace by a known time delay (δt).

Test Execution: Process the reference block, then compute Δv/v using the shifted block. Set an Alert Threshold of -1.0%.

Expected Outcome Pass/Fail Actual Outcome / Notes
The Δv/v Timeline must plot the calculated velocity change resulting from the time delay.
If the computed change is equal to or more negative than the -1.0% threshold, the red alert banner must appear at the top of the module.

Phase 4: Event Refinement and Array Operations

11. Event Catalog, Phase Picker & HypoDD

Synthetic Input: Inject two synthetic events into the SQLite historian with predefined P and S arrival times.

Test Execution: Open the Phase Picker to drag the arrival markers. Select ≥2 events in the Event Catalog and click "Run HypoDD".

Expected Outcome Pass/Fail Actual Outcome / Notes
In the Phase Picker, dragging the pick lines must update the timestamp in real-time.
The HypoDD solver must complete and automatically open a 3D Plotly modal showing the original hypocenters (faded markers) and relocated positions (solid markers).

12. Site Characterization (MASW)

Synthetic Input: A multi-channel synthetic surface wave record with known theoretical dispersion properties.

Test Execution: Compute the MASW Image, click to pick the dispersion curve, and invert the picks.

Expected Outcome Pass/Fail Actual Outcome / Notes
The dispersion energy image must render as a frequency vs. phase-velocity heatmap.
The inversion must plot a layered-earth Vs depth profile as a step function.
The module must display the appropriate NEHRP site class badge based on the computed Vs30.
