System Overview

Gaia-Argus is a high-performance desktop operator console engineered for continuous seismic telemetry ingestion, multi-station array management, and long-term structural health monitoring (SHM). Packaged as a single, self-contained Windows executable, it eliminates external runtime dependencies by bundling a compiled Rust processing core, an embedded SQLite historian, and a GPU-optional visualization layer into one coherent Tauri v2 binary.

The system is designed for deployment alongside linear sensor arrays — such as those used on high-speed rail corridors — where P-wave back-azimuth triangulation, velocity change monitoring, and rapid-onset event classification must operate continuously without operator intervention.

Zero-Allocation Real-Time Core The Rust DSP backend processes waveform data inside pre-allocated ring buffers, bypassing the garbage collector entirely. Binary IPC transfers raw f32 sample arrays as flat Vec<u8> byte vectors directly to the Canvas renderer — eliminating JSON serialization overhead and the associated multi-second latency seen in conventional WebView architectures.

Core Capabilities

Hybrid Canvas Rendering Engine

  • Binary IPC pipeline: Rust packs f32 amplitudes into a flat byte buffer with a 32-byte metadata header; the JS side casts a zero-copy Float32Array view, no JSON pass.
  • Adaptive draw loop: Per-pixel min/max envelope for overview (millions of samples at full canvas width); direct lineTo path at zoomed scales. Transition is seamless.
  • DPI-aware sizing: ResizeObserver fires devicePixelRatio-corrected canvas resize; sharp rendering on 4K and HiDPI displays.
  • Native interactivity: Wheel zoom (cursor-anchored), left-drag pan, touch pinch/pan — all in-buffer, no round-trips to Rust.

3-Component Polarization Analysis

  • Covariance eigen-decomposition: Sliding window (0.5 – 4 s, configurable overlap) constructs a 3×3 covariance matrix per window using nalgebra::SymmetricEigen (stack-allocated, zero heap).
  • P-wave detection: Rectilinearity R = 1 − (λ₂+λ₃)/(2λ₁); configurable threshold trigger (default R ≥ 0.75).
  • Back-azimuth: Derived from the principal eigenvector projected onto the horizontal plane; ±180° ambiguity resolved by the sign of the vertical component.
  • IPC telemetry: Throttled polarization_telemetry Tauri event with rectilinearity, azimuth, incidence, and eigenvalues.

Ambient Noise Interferometry (Δv/v)

  • Preprocessing: 1-bit temporal normalisation suppresses transient earthquake spikes; spectral whitening (Hann-windowed FFT, 10-bin smoothing) equalises the spectrum for broadband coherence.
  • Cross-correlation: FFT-based convolution A(ω)·B*(ω) → IFFT → fftshift; CCF normalised to [−1, 1].
  • Stacking & reference: Rolling 24 h / 5-day linear stack; persisted per station pair in SQLite.
  • Δv/v extraction: Moving Window Cross-Spectral (MWCS) analysis; weighted least-squares phase-slope fit yields δt per window → Δv/v = −δt/t.

HypoDD Relocation & Site Characterization

  • Double-difference relocation: Iterative SVD solver (nalgebra::SVD); 1-D Vp/Vs model (6.0/3.47 km/s); convergence at ‖Δm‖₂ < 0.1 m. Results visualised as 3D Plotly modal with original/relocated marker pairs.
  • MASW (Vs30): Slant-stack p-τ transform + damped least-squares inversion across 128 velocity bins; Vs30 harmonic mean with NEHRP site class badge.
  • Interactive picking: Manual dispersion curve selection via plotly_click events; picked points feed directly into the inversion.

Software Architecture

The application follows a strict two-layer architecture: a gaia_dsp library crate contains all signal processing algorithms as pure, dependency-free Rust functions; the gaia-station-app Tauri crate contains thin async command adapters that call into gaia_dsp via spawn_blocking, preventing any DSP work from blocking the Tauri event loop or the UI thread.

Subsystem Technology Role
DSP Library Rust (gaia_dsp crate) Polarization, MWCS Δv/v, HypoDD SVD relocation, MASW slant-stack, F-K beamforming. Zero UI coupling. Full unit test coverage.
Tauri Command Layer Rust / Tauri v2 Async IPC bridge. Queries SQLite via sqlx::SqlitePool, calls gaia_dsp inside spawn_blocking, emits typed events to the frontend.
Visualization UI Svelte 5 / TypeScript Canvas waveform engine, Plotly WebGL for spectral views, real-time reactive stores, MD3-compatible dark theme.
Historian SQLite3 (embedded) Event catalog, phase picks, CCF stacks, Δv/v history, station metadata — all persisted locally with no external database dependency.
Telemetry Ingest SeedLink TCP / miniSEED Live streaming via SeedLink client (configurable host:port, network/station/selector codes); offline batch ingestion of miniSEED archives and Omega directory structures.
