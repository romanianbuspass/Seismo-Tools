# Changelog

All notable changes to the GaiaCode Sensor Terminal (Mobile) will be documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-03-25

### Added
- Initial release of GaiaCode Sensor Terminal for Android/iOS
- **Bluetooth Serial** connection via Bluetooth Classic (SPP)
- **USB OTG Serial** connection for Android devices
- **4 Sensor Profiles**: Theta Pico, Theta Standard, Sigma, Alpha
- All sensor commands ported from desktop version with Unicode icons
- **Connection Screen** with device scanning, bonded device list, baud rate selection
- **Terminal Screen** with adaptive layout (tablet side-by-side, phone tabbed)
- **Command Grid** with colour-coded groups, haptic feedback, responsive columns
- **Serial Monitor** with TX/RX/system colour coding, timestamps, 5000-line buffer
- **Quick Reconnect** — remembers last connected device
- **GaiaCode branding** — logo in header, connection screen, and about
- Dark Material 3 theme matching desktop application
- Log export (save terminal output to file)
- Custom command input with send button
- Settings: CR+LF toggle, timestamp toggle, clear terminal
